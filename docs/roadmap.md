# Roadmap

This roadmap describes how Knowledge Graphs Lab can evolve from a clean research prototype into a more complete academic knowledge graph platform.

---

## Phase 1 — Foundation

Status: in progress

- [x] Professional README
- [x] SVG banner and visual previews
- [x] Sample research graph dataset
- [x] NetworkX graph builder
- [x] Basic analytics utilities

- [x] Architecture documentation

## Long-Term Vision

The long-term goal is to make this repository a reusable academic toolkit for building transparent, explainable, and evidence-grounded knowledge graph systems.
